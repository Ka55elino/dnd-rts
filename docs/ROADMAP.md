# Roadmap

Порядок важен: **данные → игра на данных → редактор для данных**.
Фазы 0–1 проверяют жизнеспособность проекта. Пока они не закрыты, остальное не начинаем.

## Фаза 0 — Фундамент

- [x] Переименовать Go-модуль (`changeme` → `dnd-rts`)
- [x] Создать структуру папок по `ARCHITECTURE.md`, удалить демо (`greetservice.go`)
- [ ] **Бенчмарк**: Go генерирует 10 000 движущихся точек → бинарный WS @ 20 Гц → `InstancedMesh` с интерполяцией
  - [ ] замер FPS и времени кадра на macOS
  - [ ] замер на Windows
  - [ ] замер на Linux (WebKitGTK)
- [ ] `internal/fixed`: тип Fixed, Vec2, арифметика, sqrt, sin/cos по таблицам + тесты
- [ ] `internal/protocol` + `frontend/src/net`: версия протокола, снапшот, команды
- [ ] `internal/data`: минимальные схемы `unit`, `horde`, `faction`, `map` + загрузка из `content/`
- [ ] Переключение режимов: меню → игра / редактор → назад (без утечек WebGL)

**Готово, когда:** бенчмарк держит 60 FPS на всех трёх ОС, а переходы между экранами не текут по памяти.

## Фаза 1 — Вертикальный срез игры

Данные пишутся руками в JSON, редактора пока нет.

- [ ] Террейн по heightmap, RTS-камера (края экрана, WASD, зум, границы карты)
- [ ] Отряд: формация, выделение кликом и рамкой, приказ «идти»
- [ ] Навигация: сетка проходимости + flow fields, удержание строя, separation
- [ ] Ближний бой: цели, урон, гибель отдельных бойцов, распад отряда
- [ ] Кавалерия: разгон, затаптывание, отбрасывание
- [ ] VAT-анимации для бойцов (idle, walk, attack, die)
- [ ] Один герой (`SkinnedMesh`) с одной активной способностью
- [ ] HUD: панель выбранного отряда, хоткеи
- [ ] Хэш состояния симуляции каждые N тиков (задел на проверку рассинхрона)

**Готово, когда:** бой 1000+ солдат идёт стабильно на Win / Mac / Linux.

## Фаза 2 — Редактор карт (MVP)

- [ ] Новая карта по размеру, сохранение и загрузка
- [ ] Кисти рельефа: поднять, опустить, сгладить, выровнять
- [ ] Раскраска террейна (splat map, 4–8 слоёв)
- [ ] Расстановка объектов: деревья, скалы, декор (инстансинг)
- [ ] Стартовые позиции, точки ресурсов, зоны непроходимости
- [ ] Undo/redo
- [ ] «Тест-запуск» карты из редактора

## Фаза 3 — Редактор контента

- [ ] Формы по схемам `internal/data`: юнит, отряд, герой, способность, фракция
- [ ] 3D-превью модели и анимаций
- [ ] Валидация ссылок (модели, способности, юниты фракции)

## Заметки

- Ассеты на старте — бесплатные заглушки (Kenney, Quaternius). Пайплайн: Blender → glTF → VAT.
- Имена, персонажи и локации Толкина защищены авторским правом. Для публичного релиза нужен свой сеттинг.
